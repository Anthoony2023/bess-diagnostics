2. Rebound phenomenon: Old > new tendency, but absolute varies, need self-baseline Growth%.
3. Baseline: Absolute value varies per cell, use self fingerprint, use Growth%.
4. Time compromise: Longer rest more accurate, field compromise 20-30min reasonable.
5. Short-rest extrapolation: If only 5min available, need to extrapolate to 30min equivalent.
6. Non-linear extrapolation: Lab 24C constant current, field varying temp/current, extrapolation not linear.
7. Data source: Cell maker data only represents one batch/model, not all cells same material/process.
8. No retest: Operators have no time/cost to retest, use maker ideal data.
9. Temperature representative points: After assembling to module/Battery Bank, temp only at key locations, cannot represent each cell.
10. Measurement uncertainty: Sensor accuracy, V/I sync, sampling rate cause dynamic impedance error.
